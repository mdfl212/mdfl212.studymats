What it understands
  • Headings (h1–h6) with their CSS color, font, size, weight and border
  • Paragraphs, bold/italic/underline/strikethrough, line breaks
  • Bulleted and numbered lists, including nested lists
  • Tables — column widths, header shading, cell borders, per-row background all read from the rendered page
  • Colored / bordered boxes (callouts, footers, dividers) — detected from any block that has its own background or border, not tied to a specific class name
  • Rows containing a right-floated element (e.g. a table-of-contents page number) are rendered with a dotted leader, right-aligned
  • Forced page breaks (page-break-before / break-before)
  • Not yet supported: embedded images, multi-column layouts
